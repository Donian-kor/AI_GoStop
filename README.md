# 명지네고스톱

가족이 같은 집에서 함께 즐길 수 있도록 만드는 고스톱 프로젝트입니다.
**3인 삼파전** · **2인 맞고** · **4인 광팔기** · **혼자 AI와 대국**을 지원하며, 실제 돈이 아닌 **가상 포인트**만 사용합니다.

> **현재 상태:** 규칙 엔진 + HTTP 서버 + 브라우저 화면 + AI 상대까지 구현되어 있습니다.
> `npm start` 로 서버를 띄우고 같은 와이파이의 폰·PC에서 접속하면 바로 칠 수 있습니다.
> 현재 버전: **v0.27**

## 버전 규칙

| 구분 | 규칙 | 예시 |
|---|---|---|
| 최초 공개 | `v0.1` | v0.1 |
| **버그 수정** | `v0.1x` | v0.11, v0.12 |
| **기능 추가** | `v0.x` | v0.2, v0.3 |
| **대규모 리팩토링·대형 기능 추가** | `vx.x` | v1.0, v2.0 |

버전 번호는 `server/version.js` 한 곳에서 관리하며, 접속 화면에도 표시됩니다.
화면·엔진·자산을 바꾼 뒤에는 `BUILD_VERSION`도 올리면 폰이 자동으로 새 화면을 받습니다.

> **v0.23 수정:** 선 결정 후보 카드가 딜 덱에서 빠져 3인 기준 9장이 사라지던 문제를 고쳤습니다. 이 때문에 점수가 나기 어려워 나가리 판이 과도하게 많았습니다.
>
> **v0.24 추가:** 로비의 **방 참가**를 누르면 만들어진 방 목록이 뜹니다. 방을 한 번 누르면 선택되고, 같은 방을 두 번 누르면(더블클릭·더블터치) 바로 참가합니다. 큰 **선택한 방 참가** 버튼으로도 들어갈 수 있고, 기존 **코드 직접 입력**도 그대로 쓸 수 있습니다.
>
> **v0.25 추가:** **방장이 나가면 그 방은 바로 사라집니다.** 대기실 목록에서도 곧바로 빠지고, 같이 있던 사람들은 "방이 닫혔습니다" 안내와 함께 대기실로 돌아갑니다. (방장이 아닌 사람이 나가는 경우는 방이 그대로 남습니다.)
>
> **v0.26 변경:** 게임 이름을 **고스톱 → 명지네고스톱**으로 바꿨습니다. (로비 큰 제목 · 브라우저 탭 · 규칙 창)
>
> **v0.27 추가:** 실제 화투를 치는 느낌의 **카드 연출**을 넣었습니다.
> - **패를 섞는 연출** — 판이 넘어가 선을 정할 때, 실제 덱(48·50·51장)만큼 뒷장 카드가 촘촘히 모여 여러 번 짧게 뒤집듯 섞인 뒤 가운데로 모입니다
> - **카드가 미끄러지는 이동** — 카드를 내면 남은 손패가 제자리로 부드럽게 이동합니다
> - **카드가 떨어지며 나타남** — 나눠받는 패와 바닥에 놓이는 패가 순서대로 나타납니다
> - **상대가 낸 패 · 먹은 패** — 상대 자리의 카드가 바닥으로 날아오고, 먹은 패는 상대의 먹은 패 자리로 날아갑니다
>
> 카드 연출은 [bipark/gostop-ts](https://github.com/bipark/gostop-ts) 의 기법(PolyForm Noncommercial 1.0.0)을 참고했습니다. 라이선스 고지는 `ATTRIBUTION.md` 에 있습니다.

## 빠른 시작 (가족용)

### 1. 아빠 PC에서 서버 실행

```bash
cd gostop-game
npm start
```

화면에 이런 식으로 나옵니다.

```
  이 PC에서 접속   :  http://localhost:8787
  같은 와이파이    :  http://192.168.x.x:8787
  .local 주소      :  http://DESKTOP-XXXX.local:8787
```

> `npm install` 은 필요 없습니다. 외부 패키지 0개입니다.

### 2. 가족들이 접속

- 폰·PC 브라우저로 위 주소(같은 와이파이) 를 엽니다
- **이름**을 입력하고 방을 만듭니다 → **6자리 방 코드**가 나옵니다 (예: `HJS7K2`)
- 다른 가족은 **방 참가**를 누르고 목록에서 방을 고릅니다 (한 번 누르면 선택, 두 번 누르면 참가)
- 방 코드를 직접 입력하려면 목록 아래 **코드 직접 입력**을 누릅니다
- 3명이 모이면 방장이 "판 시작" 을 누릅니다

### 3. 모드 고르기

방 만들 때 왼쪽 선택창에서 고릅니다.

| 화면 선택 | 구성 |
|---|---|
| **1 : 1 맞고** | 사람 2명 |
| **3명이서 하기** | 사람 3명 (3인 삼파전) |
| **넷이서 광팔기** | 사람 4명 (광팔기 — 한 명이 빠질 수 있음) |
| **AI랑 맞고** | 나 + 컴퓨터 1명 |
| **AI와 대결 3인** | 나 + 컴퓨터 2명 |

AI 난이도는 쉬움 / 보통 / 어려움 / 초고수 중에서 고릅니다.

### 4. 방 설정 (방장만)

방을 만든 뒤, **판을 시작하기 전에** 상단 **⚙** 버튼을 눌러 바꿉니다.
(판이 끝난 뒤 다음 판을 시작하기 전에도 바꿀 수 있습니다.)

- **시간제한** — 없음 / 30초+5초 / 45초+5초 / 60초+10초 (제한 시간이 지나면 자동으로 넘어갑니다)
- **점당 금액** — 10 / 100 / 500 / 1,000 / 5,000 / 10,000원 중에서 고릅니다 (기본 100원)

## 규칙 요약

- **족보**: 3광(비광 포함 2점) · 4광 4점 · 5광 15점 · 고도리 5점 · 열꽃 5장부터 1점+ · 띠 5장부터 1점+ · 홍단·청단·초단 각 3점 · 피값 10부터 1점+
- **국진**: 열꽃/쌍피 중 유리한 쪽 자동 계산. 낼 피가 없으면 국진을 넘기지 않고 열꽃으로 고정됩니다
- **고/스톱**: 3인 3점 / 2인 7점부터. 고는 계속하고 스톱은 즉시 승리. 3고부터 배수 2배
- **박**: 피박 · 광박 · 멍박 · 고박(독박)
- **특수**: 뻑 · 첫뻑 · 연뻑 · 자뻑 · 쪽 · 따닥 · 싹쓸이 · 흔들기 · 폭탄 · 총통 · 쓰리뻑 · 역고
- **정산**: (족보점수 + 고보너스) × 배수. 패자가 한 장도 못 먹으면 점수는 유지하고 지급만 면제되며, 잔액이 부족하면 빚(음수 잔액)을 허용합니다

정본 규칙은 [civilian7/gostop 의 game-rules.md](https://github.com/civilian7/gostop/blob/main/docs/game-rules.md) 를 따릅니다.
세부 규칙이 다른 부분은 [BENCHMARK.md §10](./BENCHMARK.md) 에 정리해 두었습니다.

## 구현된 기능

**게임 엔진** (`engine/`)
- 화투 48장 + 보너스패 구성(48/50/51) 덱 생성과 셔플
- 2인 맞고 · 3인 삼파전 · 4인 광팔기 패 나누기, 밤일낮장 선 결정
- 턴 진행, 카드 매칭, 특수상황 11종
- 족보 점수 · 박 · 역고 · 나가리 이월 · 가상 포인트 정산
- AI 상대 (`ai.js`) — 후보 4종(카드/폭탄/흔들기/뒤집기) 평가 + 난이도 4단계
- 4인 광팔기 협상 (`fourplayer.js`) — 참가 협상 · 광값 선불 · 연사 규칙

**서버** (`server/`)
- 방 만들기(6자리 코드) · 참가 · **폴링 동기화**(1.2초) · **손패 은닉** · 재접속 · 시간제한 · 타임아웃
- **방 목록 API** (`GET /api/rooms`) — 방장 이름·인원·빈자리·대국 단계·참가 가능 여부를 내려줍니다
- **방장이 나가면 방을 즉시 삭제** — 대기실 목록에서도 사라지고, 남은 사람들은 대기실로 돌아갑니다
- 의존성 0개 (Node 표준 라이브러리만 사용)
- 연결 끊김(배터리 방전 등) 시 자동 진행 · 1분 뒤 빈 방 정리

**화면** (`public/`)
- 진입(모드·난이도 선택) · 대국 · 선 결정 · 정산
- **카드 연출** — 패 섞는 연출 · 카드가 떨어지며 나타남 · 카드가 미끄러지는 이동(FLIP) · 상대가 낸 패·먹은 패가 날아가는 연출
- 로비 **방 참가 목록** — 한 번 누르면 선택, 두 번 누르면(더블클릭·더블터치) 참가. 새로고침·코드 직접 입력·큰 참가 버튼 제공
- 카드 비행 애니메이션(Web Animations API) · 이펙트 배너 · 효과음 · 소리 끄기
- 로비 상단 **소리**·**설정(⚙)** 아이콘 — 게임 화면과 소리 상태를 공유하고, 새 방의 점당·시간제한을 미리 고릅니다
- 족보 진행도·먹은 패 보기(광/열꽃/띠/피 분류) · 방장용 ⚙ 설정 창(시간제한·점당 금액)
- 상대가 먹은 패를 종류별 그림으로 보기 / 숫자로 보기 토글 (선택은 기기에 저장)
- 구형 안드로이드 4.4.4용 CSS fallback (CSS 변수·Grid·min() 미지원 대응)

## 자산 다운로드

자산을 다시 받는 명령입니다 (보통은 필요 없습니다).

```bash
npm run fetch-assets
```

이미 파일이 있고 원본과 크기가 같으면 건너뜁니다. 강제로 다시 받으려면:

```bash
node tools/fetch-assets.js --force
```
