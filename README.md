# 고스톱 게임

가족이 같은 집에서 함께 즐길 수 있도록 만드는 고스톱 프로젝트입니다.
**3인 삼파전** · **2인 맞고** · **혼자 AI와 대국**을 지원하며, 실제 돈이 아닌 **가상 포인트**만 사용합니다.

> **현재 상태:** 규칙 엔진 + HTTP 서버 + 브라우저 화면 + AI 상대까지 구현되어 있습니다.
> `npm start` 로 서버를 띄우고 같은 와이파이의 폰·PC에서 접속하면 바로 칠 수 있습니다.
> 현재 버전: **v0.19**

## 버전 규칙

| 구분 | 규칙 | 예시 |
|---|---|---|
| 최초 공개 | `v0.1` | v0.1 |
| **버그 수정** | `v0.1x` | v0.11, v0.12 |
| **기능 추가** | `v0.x` | v0.2, v0.3 |
| **대규모 리팩토링·대형 기능 추가** | `vx.x` | v1.0, v2.0 |

버전 번호는 `server/version.js` 한 곳에서 관리하며, 접속 화면에도 표시됩니다.
화면·엔진·자산을 바꾼 뒤에는 `BUILD_VERSION`도 올리면 폰이 자동으로 새 화면을 받습니다.

## 빠른 시작 (가족용)

### 1. 아빠 PC에서 서버 실행

```bash
cd gostop-game
npm start
```

화면에 이런 식으로 나옵니다.

```
  이 PC에서 접속   :  http://localhost:8787
  같은 와이파이    :  http://192.168.x.x:8787
  .local 주소      :  http://DESKTOP-XXXX.local:8787
```

> `npm install` 은 필요 없습니다. 외부 패키지 0개입니다.

### 2. 가족들이 접속

- 폰·PC 브라우저로 위 주소(같은 와이파이) 를 엽니다
- **이름**을 입력하고 방을 만듭니다 → **6자리 방 코드**가 나옵니다 (예: `HJS7K2`)
- 다른 가족은 "방 참가" 를 누르고 그 코드를 입력합니다
- 3명이 모이면 방장이 "판 시작" 을 누릅니다

### 3. 혼자 치고 싶을 때

방 만들 때 왼쪽 선택창에서 고릅니다.

| 선택 | 구성 |
|---|---|
| **3명 (가족과 함께)** | 사람 3명 |
| **2인 맞고** | 사람 2명 |
| **혼자 · AI와 2인** | 나 + 컴퓨터 A |
| **혼자 · AI와 3인** | 나 + 컴퓨터 A·B |

AI 난이도는 쉬움 / 보통 / 어려움 / 초고수 중에서 고릅니다.

### 4. 방 설정 (방장만)

대국 중 상단에서 바꿀 수 있습니다.

- **시간제한** — 없음 / 30초+5초 / 45초+5초 / 60초+10초 (제한 시간이 지나면 자동으로 넘어갑니다)
- **점당 금액** — 1점이 몇 포인트인지 (기본 100P)

## 규칙 요약

- **족보**: 3광(비광 포함 2점) · 4광 4점 · 5광 15점 · 고도리 5점 · 열꽃 5장부터 1점+ · 띠 5장부터 1점+ · 홍단·청단·초단 각 3점 · 피값 10부터 1점+
- **국진**: 열꽃/쌍피 중 유리한 쪽 자동 계산. 낼 피가 없으면 국진을 넘기지 않고 열꽃으로 고정됩니다
- **고/스톱**: 3인 3점 / 2인 7점부터. 고는 계속하고 스톱은 즉시 승리. 3고부터 배수 2배
- **박**: 피박 · 광박 · 멍박 · 고박(독박)
- **특수**: 뻑 · 첫뻑 · 연뻑 · 자뻑 · 쪽 · 따닥 · 싹쓸이 · 흔들기 · 폭탄 · 총통 · 쓰리뻑 · 역고
- **정산**: (족보점수 + 고보너스) × 배수. 패자가 한 장도 못 먹으면 점수는 유지하고 지급만 면제됩니다

정본 규칙은 [civilian7/gostop 의 game-rules.md](https://github.com/civilian7/gostop/blob/main/docs/game-rules.md) 를 따릅니다.
세부 규칙이 다른 부분은 [BENCHMARK.md §10](./BENCHMARK.md) 에 정리해 두었습니다.

## 구현된 기능

**게임 엔진** (`engine/`)
- 화투 48장 + 보너스패 구성(48/50/51) 덱 생성과 셔플
- 2인 맞고 · 3인 삼파전 패 나누기, 밤일낮장 선 결정
- 턴 진행, 카드 매칭, 특수상황 11종
- 족보 점수 · 박 · 역고 · 나가리 이월 · 가상 포인트 정산
- AI 상대 (`ai.js`) — 후보 4종(카드/폭탄/흔들기/뒤집기) 평가 + 난이도 4단계

**서버** (`server/`)
- 방 만들기(6자리 코드) · 참가 · **폴링 동기화**(1.2초) · **손패 은닉** · 재접속 · 시간제한 · 타임아웃
- 의존성 0개 (Node 표준 라이브러리만 사용)
- 연결 끊김(배터리 방전 등) 시 자동 진행 · 1분 뒤 빈 방 정리

**화면** (`public/`)
- 진입(모드·난이도 선택) · 대국 · 선 결정 · 정산
- 카드 비행 애니메이션(Web Animations API) · 이펙트 배너 · 효과음 · 소리 끄기
- 구형 안드로이드 4.4.4용 CSS fallback (CSS 변수·Grid·min() 미지원 대응)

## 테스트

```bash
npm test
```

전체 **73개**가 모두 통과해야 합니다.

| 명령 | 내용 | 개수 |
|---|---|---|
| `npm run test:engine` | 규칙 엔진 단위 테스트 | 44 |
| `npm run test:contract` | 카드·점수 계약 테스트 | 10 |
| `npm run test:replay` | 기록 재생 스모크 테스트 | 3 |
| `npm run test:server` | HTTP 통합 테스트 (3인 실전 대국 → 정산) | 3 |
| `npm run test:ai` | AI 상대 대국 테스트 | 3 |
| `npm run test:disconnect` | 연결 끊김 자동 진행·바닥 선택 회귀 테스트 | 4 |
| `npm run test:jokbo` | 족보 그림 타일 렌더 테스트 | 4 |
| `npm run test:deal` | 딜 직후 총통 정산 테스트 | 2 |

Node.js 기본 `node:test` 를 사용하므로 외부 테스트 패키지가 필요 없습니다.

## 자산 다운로드

자산을 다시 받는 명령입니다 (보통은 필요 없습니다).

```bash
npm run fetch-assets
```

이미 파일이 있고 원본과 크기가 같으면 건너뜁니다. 강제로 다시 받으려면:

```bash
node tools/fetch-assets.js --force
```

자산별 저작자와 라이선스는 [ATTRIBUTION.md](./ATTRIBUTION.md) 를 참고하세요.
소스 코드는 [LICENSE](./LICENSE) 의 MIT License 를 따르며, 포함된 이미지와 효과음에는 각각의 원래 라이선스가 적용됩니다.
